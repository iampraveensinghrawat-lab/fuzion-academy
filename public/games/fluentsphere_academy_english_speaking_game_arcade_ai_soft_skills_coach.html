        Project Structure & How to Upload HTML Games and PDFs

        // Recommended Modular Project Structure
        fluent-sphere-academy/
        ├── server.js            # Node.js + Express static & API server
        ├── package.json
        ├── README.md
        └── public/
            ├── index.html       # Main Academy Web App
            ├── js/
            │   ├── games-registry.js
            │   ├── pdf-registry.js
            │   └── speaking-coach.js
            ├── games/           # <-- DROP YOUR .HTML GAMES HERE
            │   ├── vocab-surge.html
            │   ├── grammar-detective.html
            │   └── my-custom-game.html
            └── pdfs/            # <-- DROP YOUR .PDF FILES HERE
                ├── interview-handbook.pdf
                └── business-phrases.pdf

        Step 1: Uploading Your HTML5 Game Files

        1. Copy your standalone .html game file into public/games/.
        2. If your game uses relative assets (images/CSS), keep them in a subfolder like public/games/my-game/index.html.
        3. Add an entry in public/js/games-registry.js with fileUrl: 'games/my-game.html' (or when running Express, the server auto-discovers every .html file in public/games/!).
        4. Instant Browser Test: Click "Upload Custom .HTML Game" in the Game Arcade tab right now to test any local file!

        Step 2: Uploading Your PDF Study Materials

        1. Place your .pdf documents inside public/pdfs/.
        2. Register the title, category (Daily Vocabulary, Interview Handbooks, Grammar Guides, or Business English Phrases), and pdfUrl: 'pdfs/your-file.pdf' in public/js/pdf-registry.js.
        3. Instant Browser Test: Click "Add Custom .PDF to Library" in the Study Material Hub tab to test uploading a PDF immediately.
        Download the companion fluent_sphere_academy_project.zip for the ready-to-run Node.js + Express folder structure.
        Action completed!
